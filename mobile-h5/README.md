# 校园活动报名 · 手机版（H5）

把原来的 PC 版（Vue 3 + Element Plus）改写为**手机浏览器直接打开**的移动版，功能一一对应，原来的 `frontend` 目录未做任何改动。

## 一、三种打开方式

### 方式 A：电脑起服务，手机同 Wi-Fi 访问（推荐，演示最完整）

1. 双击本目录下的 **`启动手机版.bat`**（首次会自动 `npm install`）。脚本会自动查找本机 Node.js 的安装位置（常见目录 + PATH），不依赖环境变量是否生效。
2. 窗口里会打印访问地址，例如：
   - 电脑：`http://localhost:5173`
   - 手机：`http://172.17.42.64:5173`
3. 手机连**同一个 Wi-Fi**，浏览器输入上面那个手机地址即可。
4. 若手机打不开，先双击 **`允许手机访问.bat`**（右键“以管理员身份运行”），放行 5173 端口后再试。

> 电脑的 IP 会随网络变化，以启动窗口里打印的地址为准。
> 停止服务：在该窗口按 `Ctrl + C`。

### 方式 B：单文件离线版（不需要电脑、不需要后端）

目录里已经有一个打包好的 **`校园活动.html`**（约 140 KB，单文件、无外部依赖，和 `dist/index.html` 内容相同）：

1. 通过微信 / QQ / 数据线把 `校园活动.html` 发到手机；
2. 手机用浏览器打开这个文件即可使用（微信里若不能直接打开，可先“用其他应用打开”选浏览器）。

此方式完全离线，数据来自内置演示数据，保存在手机浏览器本地，适合只做界面与流程演示。

### 方式 C：部署到服务器

`npm run build` 生成 `dist/index.html`（单文件），上传到任意静态托管即可访问。
若要连真实后端，把接口地址改成同域路径或设置环境变量 `VITE_API_BASE`：

```bash
set VITE_API_BASE=https://你的域名/api
npm run build
```

## 二、和原后端的关系

- 手机端所有请求走相对路径 `/api`，开发服务器（Vite）把它代理到 `http://localhost:8080`，因此**浏览器端不存在跨域问题，原后端无需改 CORS**。
- 后端没启动、或手机连不上时，前端会自动切换到**内置演示数据**，页面不会白屏，顶栏会显示橙色「演示数据」标记。
- 「我的」页里可以：
  - 点「重新连接后端」重试真实接口；
  - 点「重置演示数据」把演示活动恢复为初始 6 条。

### 连真实后端的步骤

1. 启动 MySQL，执行 `database/campus_activity.sql`；
2. 修改 `backend/src/main/resources/application.properties` 中的数据库密码；
3. 运行 `CampusActivityApplication`（端口 8080）；
4. 手机打开手机版页面，顶栏橙色「演示数据」消失、变成正常状态即表示已连上。

账号：`student01 / 123456`（学生）、`student02 / 123456`（学生）、`admin / 123456`（管理员）。

## 三、功能对照

| 原 PC 版 | 手机版实现 |
| --- | --- |
| 顶部横向导航 | 顶部状态栏 + 底部 Tab 导航（活动 / 我的报名 / 活动管理 / 我的） |
| Element Plus 表格 | 卡片式列表，适合拇指点按 |
| el-input / el-select | 原生 input / select，手机键盘与系统控件 |
| el-date-picker | 原生 `datetime-local`，直接调用手机日期时间选择器 |
| ElMessage / ElMessageBox | 自研轻提示（Toast）与底部确认弹窗 |
| 活动列表、搜索、分类筛选 | 保留，搜索框 + 横向分类 chips |
| 详情、报名、取消报名 | 保留，底部固定操作栏 |
| 我的报名、取消报名 | 保留，卡片列表 |
| 管理员发布/编辑/删除、报名名单 | 保留，管理列表 + 底部弹出式删除确认 |

登录状态仍存 `localStorage`（键名 `campusUser`），与原版一致，刷新不丢。

## 四、目录结构

```
mobile-h5/
├─ 启动手机版.bat          # 双击入口（纯批处理，自动定位 npm 并启动 5173）
├─ start-mobile.ps1        # 安装依赖、打印手机访问地址、启动服务
├─ 允许手机访问.bat        # 右键管理员运行，调用 allow-firewall.ps1 放行 5173
├─ allow-firewall.ps1      # 防火墙放行脚本（仅专用网络）
├─ 校园活动.html           # 单文件离线版，可直接发到手机打开
├─ dist/index.html         # npm run build 生成的单文件产物
├─ screenshots/            # 界面截图
├─ src/
│  ├─ api.js               # 接口层：/api + 后端不可用时自动降级演示数据
│  ├─ mock.js              # 内置演示数据，语义与后端一致
│  ├─ store.js             # 登录状态（沿用原 localStorage 结构）
│  ├─ ui.js                # Toast 与确认弹窗
│  ├─ format.js            # 手机端短日期格式
│  ├─ router.js            # hash 路由，任意静态路径都能打开
│  ├─ App.vue              # 顶栏 + 底部 Tab + 全局交互
│  ├─ style.css            # 移动端设计系统（深蓝主色、卡片、安全区适配）
│  └─ views/               # 登录、列表、详情、我的报名、管理、表单、名单、个人中心
└─ vite.config.js          # 代理 /api → 8080；打包为单文件
```

## 五、常见问题

- **手机打不开页面**：确认手机和电脑在同一 Wi-Fi；确认启动窗口显示的 IP 与输入一致；放行防火墙。
- **双击 `启动手机版.bat` 一闪就关**：说明脚本没找到 npm（Node.js 未装或安装目录不在 PATH）。窗口里会明确提示 `[ERROR] npm was not found`，先装 Node.js 20+ 再试；已装但装在别的盘时，把安装目录加进系统环境变量 `Path`，或在 `启动手机版.bat` 里补一行 `if exist "你的盘:\...\npm.cmd" set "NPM=你的盘:\...\npm.cmd"`。
- **一直显示「演示数据」**：后端没启动或数据库没连上，属正常降级；按上面步骤启动后端后点「重新连接后端」。
- **报名记录刷新后还在**：真实后端写数据库；演示模式写手机浏览器 localStorage，换手机/清缓存会重置。
- **页面显示为电脑版宽度**：手机版最大宽度 560px 居中，横屏或大屏平板会居左留白，属设计预期。
- **想改主题色**：改 `src/style.css` 顶部 `--brand` 等变量即可。

## 六、说明

这是课程演示项目。原版说明同样适用：登录为明文密码比对，前端 localStorage 里的角色不能作为生产环境身份认证；正式部署应改用 BCrypt、Spring Security、JWT/Session 与服务端权限校验。
