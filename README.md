# CampusActivity
校园活动报名管理系统

一、项目简介

本项目是一个校园活动报名管理系统，主要用于帮助学校管理校园活动信息，实现学生在线查看活动、报名参加活动等功能。

二、开发技术

后端：Java、Spring Boot

前端：HTML、CSS、JavaScript

数据库：MySQL

开发工具：IntelliJ IDEA

项目管理：Git、GitHub

三、主要功能

用户注册与登录

校园活动信息展示

活动发布与管理

学生在线报名

报名信息管理

活动报名记录查询
